# Excel BI Sales Dashboard

My first Business Intelligence Analyst practice project using Microsoft Excel.

## Work completed
- Cleaned raw sales data
- Removed duplicate records
- Standardized Region, Product, and Customer Type fields
- Created a Month field
- Built PivotTables for monthly sales and profit
- Analyzed top products and regions
- Created KPI metrics

## Key results
- Total Sales: 81,061.40
- Total Profit: 32,976.76
- Profit Margin: 41%
- Total Orders: 300

## Tools
Microsoft Excel, PivotTables, formulas, data cleaning, dashboard reporting.
